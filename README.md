# Global EnerTec AG — Website

Die veröffentlichte Website der Global EnerTec AG, ausgeliefert über GitHub Pages
unter **https://www.global-enertec.de**

Statische Seiten, kein Redaktionssystem, keine Datenbank. Deutsch unter `de/`,
Englisch unter `en/`.

Dieses Repository enthält ausschließlich die veröffentlichten Dateien. Gepflegt
wird die Website in einem separaten, privaten Repository.
